Dr. Mente — Configuração Inicial

Configure seu projeto Firebase para salvar seus dados na nuvem com segurança.

Passo 1

Acesse console.firebase.google.com e clique em "Adicionar projeto". Dê o nome "DrMente" e siga até criar o projeto.

Passo 2

Dentro do projeto, clique no ícone Web (</>) para adicionar um app web. Dê o nome "DrMente" e clique em "Registrar app".

Passo 3

Copie o bloco firebaseConfig = { ... } que aparecer e cole abaixo (apenas o conteúdo das chaves { }).

Passo 4

Vá em Authentication → Primeiros passos → Google, ative e salve. Depois vá em Firestore Database → Criar banco de dados → Produção.

Passo 5

Em Firestore → Regras, cole este texto e publique:
rules_version='2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/{document=**} { allow read, write: if request.auth!=null && request.auth.uid==userId; } } }

Só você terá acesso — autenticação via sua conta Google.
